## 📋 نبذة عن اللعبة | About the Game

**Maghribwin** هي منصة ألعاب تفاعلية تجمع بين الترفيه والثقافة المغربية الأصيلة. تتضمن مجموعة متنوعة من الألعاب التي تجمع بين المرح والتحدي، مصممة خصيصاً لتسلية اللاعبين من جميع الأعمار.

**Maghribwin** is an interactive gaming platform that combines entertainment with authentic Moroccan culture. It features a diverse collection of games designed to provide fun and challenge for players of all ages.

## 🚀 البدء السريع | Quick Start

### المتطلبات | Requirements:
- متصفح حديث | Modern Web Browser
- اتصال إنترنت | Internet Connection
- Node.js (للتطوير) | Node.js (for Development)

### التثبيت | Installation:

```bash
# استنساخ المشروع | Clone the repository
git clone https://github.com/fahdjelloul/Maghribwin-Game.git
cd Maghribwin-Game

# تثبيت المكتبات | Install dependencies
npm install

# تشغيل السيرفر | Run the server
npm start

# افتح المتصفح وانتقل إلى | Open browser and go to:
http://localhost:3000
```

### الاستخدام | Usage:

1. 🎮 **اختر لعبة** | Choose a Game
2. 🕹️ **ابدأ باللعب** | Start Playing
3. 🏆 **جمّع النقاط** | Collect Points
4. 📊 **تابع إحصائياتك** | Track Your Stats
